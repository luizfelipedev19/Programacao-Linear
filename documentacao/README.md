# Documentação do SuínoNutri

Site de documentação (Docusaurus) do trabalho de Programação Linear. As páginas ficam em `docs/`.

```bash
npm install
npm start -- --port 3001    # http://localhost:3001/Programacao-Linear/
npm run build               # gera o site estático em build/
```

Fórmulas usam KaTeX (`$...$`) e diagramas usam Mermaid (blocos ` ```mermaid `).
